# Which string is this? 🎻

A clean, responsive web game for practicing and identifying open strings on string instruments (Violin, Viola, Cello, and Double Bass).

## Features
- **4 Instruments**: Violin, Viola, Cello, and Double Bass with realistic SVG illustrations.
- **Open String Matching**: Match note letters (A–G) to open strings (Strings IV to I) or identify notes that don't exist as open strings.
- **Multilingual**: Supports English, Hebrew (עברית, RTL), and Russian (Русский).
- **Streak Scoring**: Score tracks your consecutive streak, saving your best record in local storage.
- **Mobile Friendly**: Touch-optimized layout with full-lane touch targets.

## Quick Start
Open `index.html` in any modern web browser, or serve locally:
```bash
python -m http.server 8000
```
